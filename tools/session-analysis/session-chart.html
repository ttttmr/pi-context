如何解读

重读只是一条检查线索，不自动判为浪费。恢复观察取摘要分支后最多 10 次工具调用，遇到下一次 compact 停止；首个普通工具动作不等于有效业务进展。没有压缩的区间也保留完整工具路径。

按文件记录顺序展示全部历史分支，不伪装为单一线性对话。上下文导航不回滚外部文件。活动时段按超过 30 分钟的无记录间隔分组，不代表任务阶段；“折叠空闲”横轴移除这些间隔，实际时间模式则保留等待。

上下文 = input + cacheRead + cacheWrite；累计另加 output，含已记录辅助 usage，缓存每次读取重复计入。工具输出按文本字符统计，不是 token。调用和结果时间是记录时间，执行耗时未知。无 usage 也可分析工具行为。

默认不导出命令、参数正文、用户正文、工具输出正文或摘要正文。仍保留工具名、文件目标简称、checkpoint 名称、时间及 ID，分享前需检查。Skill 读取哈希只对应返回文本；部分读取不能证明完整版本，调用 context 工具也不证明由 Skill 导致。
